API do Tribunal Fictício

Esta API é de mentira e existe para a aula. Ela só responde a pedidos de leitura (GET), todo endereço termina em .json, e o que vier depois de um ? no endereço é ignorado.

Endereços

EndereçoO que devolve
/api/processos/NUMERO.jsonUm dicionário com os dados de um processo.
/api/processos.jsonUma lista com os 7 processos do cadastro, um dicionário por processo.
/api/decisoes/pagina-N.jsonA página N da busca por "dano moral", com 3 números por página. São 3 páginas com resultado; a página 4 existe e vem vazia.

Todos começam por https://brunodcdo.com.br/cdad1-slides/tribunal-ficticio.

Um processo

import requests

base = "https://brunodcdo.com.br/cdad1-slides/tribunal-ficticio"
url = base + "/api/processos/0000101-95.2026.8.99.0001.json"
resposta = requests.get(url)
print(resposta.status_code)
dados = resposta.json()
print(dados["partes"]["autor"])

Um número que não está no cadastro

O processo 0000999-11.2026.8.99.0001 não existe aqui. O pedido volta com status 404, e o corpo é uma página HTML de erro, e não JSON: chamar resposta.json() nesse caso dá erro. Confira o status_code antes de ler o corpo.
